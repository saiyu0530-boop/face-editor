FACE CONFIGURATION STUDIO

写真から
顔の特徴を測る。

顔写真から目・鼻・口・輪郭の位置関係を抽出する試験版です。ここで測定した特徴量を、次の段階でワイルズの実際の編集項目へ対応付けます。

01 / PROFILE

MEN profile selected

02 / FACE IMAGE

写真データはブラウザ内で処理し、画像そのものをサーバーへ送信しません。初回は解析ライブラリと学習モデルを外部CDNから読み込みます。

03 / LOCAL FACE ANALYSIS

写真を選択すると解析できます。正面に近い写真ほど測定が安定します。

表示値は顔ランドマーク間の比率です。ゲーム内スライダー値ではありません。斜め顔・強い表情・髪や手による隠れがあると誤差が増えます。

04 / FACE SHAPE（形状優先）

アップロードした人物写真の形状を測定します。肌・髪・瞳などの色は評価しません。測定比率とゲーム内設定値は別物です。根拠のない数値は自動入力しません。

写真を選択して「顔の特徴を解析」を押してください。

04 / EYE MEASUREMENTS（目元）

「顔の特徴を解析」を実行すると、左右それぞれの目の幅・開き・目尻の傾きと、左右差を表示します。ゲーム内では左右共通の設定値です。左右を別々に測定した値は平均して比較します。写真の形状から暫定的なゲーム内設定候補を自動計算します。実際のゲームとの対応は未検証です。画像の撮影条件が違うと精度は保証できません。

顔写真を選択して、顔の特徴を解析してください。

角度は画像平面上の値です。顔の傾き・表情・撮影角度に影響されるため、正面・無表情の写真を推奨します。

写真から作る目もと設定レシピ（暫定）

02 / FACE IMAGEで選んだ写真を解析し、目元の形状からゲーム内入力候補を算出します。0〜20は今回の暫定的な換算範囲であり、ゲーム内の正式な上限や正解値を保証しません。目の奥行き・二重まぶたは保留します。

05 / HAIR EDIT (髪)

動画で確認した女性ハンターの髪型タイプ1〜45を選択できます。45は動画内で確認できた番号であり、ゲーム内の最大番号とは限りません。髪の長さは暫定0〜10の操作範囲です。

アップロード動画から45枚の実画像を抽出して内蔵しました。動画を時間順に45分割したため、各画像とゲーム内番号の厳密な一致は未検証です。

タイプ1

このタイプの参考画像はまだ登録されていません。

写真から髪型を推定（実験版）

顔検出と画像の色の違いから、髪の広がり・顔周辺の下方向への伸び・前髪らしい色差を暫定推定し、4タイプ（1・25・35・41）を比較します。41種類の識別やゲーム内の最適値を保証するものではありません。背景・服・髪色で誤判定します。

顔写真を選ぶと推定できます。
45タイプの動画抽出画像ライブラリ

番号1〜45の枠を用意しました。ゲーム画面のスクリーンショットを選択中の番号へ登録できます。登録画像はこの端末のブラウザ内に保存します（容量制限あり）。未登録番号を推定済みとは扱いません。

※ 画像は実際の動画のフレームです。各番号への割り当ては動画の等間隔抽出による暫定対応で、番号の正確性は未検証です。

各項目の「− 1」「＋ 1」で1段階ずつ調整できます。男性の髪型番号への適用は未確認です。初期参考画像は動画から45枚を抽出済みです。残りは画像を登録して補完できます。写真からの髪型推定は実験段階です。色の設定は今回含めていません。

05A / EYE CALIBRATION LOG（目元の校正記録）

ゲーム画面で実際に設定した値を記録する実験用フォームです。写真の測定値と組み合わせてJSONに保存します。ゲーム内の値を自動推定する機能ではありません。

写真を解析し、ゲーム内で確認した数値を入力してください。
同じ項目の記録を2件以上保存すると、設定値と測定値の差を比較できます。
校正データの品質を確認します。
読み込み前の記録は、このページを閉じると消えます。JSONを保存してから終了してください。

注意：同じ写真の測定値に異なるゲーム設定値を付けても、変化量の校正にはなりません。ゲーム内の設定変更前後を同じ角度・表情で測定した独立データが必要です。

06 / HAIR SETTINGS OUTPUT

髪のタイプは手動選択です。髪の長さの最小・最大値はゲーム画面との追加照合が必要です。
